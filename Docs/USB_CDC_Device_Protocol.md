# H743 USB CDC Device 协议

## 硬件与运行方式

- USB OTG FS Device 使用 `PA11/USB_DM`、`PA12/USB_DP`。
- 设备枚举为 CDC 虚拟串口，产品字符串为 `H743 Spectrum Analyzer`。
- 上电后默认持续分析并上报最新结果。
- USB 发送不阻塞采样：正在发送的数据保持不变；若主机读取较慢，尚未发送的旧分析结果会被最新结果覆盖。
- PG7 为运行灯，每 500 ms 翻转一次。

## 通用帧格式

所有多字节整数均为小端序。

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 1 | 帧头 `0xA5` |
| 1 | 1 | 帧头 `0x5A` |
| 2 | 1 | 协议版本 `0x01` |
| 3 | 1 | 消息类型 |
| 4 | 2 | 帧序号 |
| 6 | 2 | Payload 长度 |
| 8 | N | Payload |
| 8+N | 2 | CRC16，低字节在前 |

CRC 使用 `CRC-16/CCITT-FALSE`：多项式 `0x1021`、初值
`0xFFFF`、不反射、不异或，计算范围为偏移 2 到 Payload 末尾。

## 主机命令

| 类型 | 名称 | Payload |
|---:|---|---|
| `0x01` | START_STREAM | 无 |
| `0x02` | STOP_STREAM | 无 |
| `0x11` | GET_STATUS | 无 |

## 设备消息

| 类型 | 名称 | 说明 |
|---:|---|---|
| `0x70` | ACK | 命令接受 |
| `0x71` | ERROR | 命令或参数错误 |
| `0x72` | STATUS | USB 状态及错误计数 |
| `0x80` | ANALYSIS | 最新分析结果 |

ACK/ERROR Payload 为两字节：原命令类型、状态码。

### STATUS Payload

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 1 | 格式版本 |
| 1 | 1 | 是否上报结果 |
| 2 | 1 | USB 是否连接 |
| 3 | 1 | USB 是否正在发送 |
| 4 | 4 | RX 溢出字节数 |
| 8 | 4 | CRC 错误数 |
| 12 | 4 | 格式错误数 |
| 16 | 4 | 控制回复丢弃数 |
| 20 | 4 | USB BUSY 重试数 |
| 24 | 4 | USB 发送错误数 |
| 28 | 4 | 被覆盖的旧结果数 |
| 32 | 4 | 最近分析序号 |
| 36 | 4 | 最近结果时间戳，ms |
| 40 | 4 | ADC 采样率，Hz |
| 44 | 4 | 处理采样率，Hz |
| 48 | 4 | 输入点数 |
| 52 | 4 | FFT 点数 |
| 56 | 4 | 修复/判坏采样点数 |
| 60 | 4 | 分析耗时，us |

### ANALYSIS Payload（53 字节）

频率使用毫赫兹整数，电压使用微伏整数。

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 1 | 分析模式 |
| 1 | 1 | 分量数，最多 3 |
| 2 | 4 | 状态标志 |
| 6 | 4 | 32 位分析序号 |
| 10 | 4 | 基频，mHz |
| 14 | 4 | 峰峰值，uV |
| 18 | 4 | 有效值，uV |
| 22 | 4 | THD，ppm |
| 26 | 9 | 第 1 个分量 |
| 35 | 9 | 第 2 个分量 |
| 44 | 9 | 第 3 个分量 |

每个分量依次包含：1 字节谐波次数、4 字节实测峰值 uV、4 字节补偿后
设定峰值 uV。分量频率由主机按“基频 × 谐波次数”得到。

完整分析协议帧为 `8 + 53 + 2 = 63` 字节，通常只占一个 USB FS Bulk 包。
采样率、FFT 点数、坏点数和分析耗时等低频诊断信息仅在 `STATUS` 中发送。

主机应把 CDC 当作字节流，按帧头、长度和 CRC 解包；不要假设一次
USB 读取恰好对应一帧。
