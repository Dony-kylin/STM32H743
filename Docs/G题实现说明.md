# 周期信号测量分析装置（G题）固件实现说明

## 1. 工程边界

本工程是STM32H743测量前端，负责AD9220采集、抗干扰、频率与幅值计算、
Vpp/Vrms/THD计算以及USB CDC上报。当前构建不初始化LCD，也没有按键扫描。
原题要求的“显示屏尺寸不小于6英寸”“显示1个或3个完整周期”“定性频谱
绘制”由USB下游显示控制器完成。H743提供绘图所需的基频、谐波阶次和
分量幅值，下游无需接收16384点原始波形。

## 2. 原题要求与固件对应关系

| 原题要求 | 固件实现 |
|---|---|
| 第一问：100～250 mVpp，所有分量10～200 kHz | 统一的8～510 kHz搜索范围覆盖该频段 |
| 第二问：50～250 mVpp，所有分量10～500 kHz | 16384点、8 MSPS处理链，搜索上限510 kHz |
| 第三问：叠加200 mVpp、频率不低于1 MHz的单频干扰 | 所有工况统一走64阶FIR抗干扰路径，并补偿通带增益 |
| 信号由基波和1个或2个谐波组成 | 最多输出3个分量，按频率排序并标记谐波阶次 |
| Vpp、Vrms误差绝对值不大于5 mV | 联合正弦拟合、前端增益标定、Vpp融合及UTG双量程标定 |
| 基频误差绝对值不大于1 kHz | Hann窗FFT找峰、对数抛物线插值、整帧正弦拟合 |
| 各频谱分量幅值误差绝对值不大于5 mV | 原始8 MSPS数据上对所有分量联合最小二乘拟合 |
| 每项完成时间不超过2秒 | 2.048 ms采集；下一块DMA与当前块分析重叠；USB只发送最新结果 |
| 真有效值 | 对联合拟合后的交流波形平方、求平均、开方，排除直流偏置 |
| 电压频谱 | 上报基频、最多3个分量的谐波阶次和Vpeak幅值 |

## 3. 实际运行数据链

```text
TIM4_CH4（PD15，8 MHz）
  -> AD9220锁存12位并行数据
  -> DMA1 Stream0读取GPIOE
  -> DMAMUX事件触发DMA1 Stream1读取GPIOD
  -> 双缓冲D2 SRAM
  -> 去流水线延迟、拼接D0～D11、转Q15
  -> 修复孤立毛刺和接近满量程的异常点
  -> 64阶FIR抗干扰
  -> 16384点Hann窗FFT
  -> 找出最强的最多3个分量并进行频率插值
  -> 根据频率比标记H1、H2……H16
  -> 在原始8 MSPS整帧上联合最小二乘拟合
  -> 频率/幅值/Vrms帧间稳定化
  -> 44%时域Vpp + 56%零相位分量重构Vpp
  -> 92.2 mV分界的UTG双量程Vpp校准
  -> THD与整数单位转换
  -> CRC16保护的USB CDC分析帧
```

## 4. 采集为什么使用双GPIO DMA

AD9220的12根数据线分布在GPIOE和GPIOD。CPU无法在8 MHz下逐点进入中断，
因此TIM4更新事件驱动GPIOE DMA；GPIOE对应的DMAMUX事件再触发GPIOD DMA。
两个DMA使用同一采样节拍。只有两个端口对应的缓冲区都完成，当前采集块
才有效。缓冲区具有代数计数，CPU复制期间如果DMA重新写入该缓冲区，整块
数据会被丢弃，避免把两帧拼成一帧。

采样块为16384点：

```text
16384 / 8 MHz = 2.048 ms
```

采集完成后先启动下一块DMA，再处理已经复制到私有工作区的上一块，采集
和FFT计算因此可以重叠。

## 5. 频率与分量识别

生成模型对FIR输出加Hann窗并执行16384点FFT，频率栅格为：

```text
8 MHz / 16384 = 488.28125 Hz
```

算法在8～510 kHz内选择最强的最多3个局部峰，并使用相邻三个频点的对数
抛物线插值降低栅栏误差。三个频率从低到高排序，最低频率视为基波；其他
频率除以基频并四舍五入，在误差小于0.15阶时标记为对应谐波次数。

FFT只负责找频率。最终幅值不是直接读取单个FFT频点，而是在原始16384点
数据上同时拟合：

```text
x[k] = DC + Σ(Cn*cos(2πfn k/Fs) + Sn*sin(2πfn k/Fs))
An = sqrt(Cn² + Sn²)
```

联合拟合能抑制直流偏置、非整数周期泄漏以及强基波对弱谐波的串扰。

## 6. 第三问抗干扰

包装层不再按题号切换算法，而是三种工况统一执行题目3的64阶FIR路径。
这样第一、二问也获得相同的高频干扰抑制。模型对每个识别频率计算FIR
幅频响应并补偿通带衰减，防止抗干扰滤波器本身造成幅值系统误差。

第三问的1 MHz以上单频干扰被FIR抑制，而且有效分量搜索只到510 kHz，
因此干扰不会作为基波或谐波上传。异常点修复数量和处理耗时仍会通过状态
帧上报，便于判断输入过载或硬件采集异常。

## 7. Vpp、Vrms与双量程校准

联合拟合系数包含ADC端的实际相位。由这些系数重构的时域Vpp能描述实际
波形，但模拟通道对不同谐波的相对相移可能使它偏离信号发生器屏幕设定值。
题目以发生器设置参数为标称值，因此固件同时用测得的分量幅值、谐波阶次
和零初相位重构一个周期，再进行：

```text
融合Vpp = 0.44 * 实际相位时域Vpp
        + 0.56 * 零相位分量重构Vpp
```

分量无效时退回时域Vpp。融合值随后按照92.2 mV测量值分界，使用两段线性
公式换算成UTG2062X屏幕等效Vpp。该校准只作用于Vpp，不缩放Vrms和频谱
分量幅值。

Vrms由拟合交流波形计算，直流项不参与，因此符合原题“真有效值”说明。
不同整数倍频率分量在完整周期上正交，Vrms对相对相位不敏感。

## 8. THD

THD直接使用识别到的物理分量幅值：

```text
THD = sqrt(A2² + A3² + ...) / A1
```

可用于THD的谐波阶次为2～16。这里的“16次”是允许参与计算的最高阶次；
同时存在的分量数量仍受题目和结果结构限制，最多为基波加两个谐波。

## 9. USB与显示控制器

USB CDC使用带帧头、版本、消息类型、序号、长度和CRC16的二进制协议。
分析帧为63字节，可放入一个USB FS Bulk包。主要结果使用整数单位：频率
为mHz，电压为uV，THD为ppm，避免不同编译器浮点格式问题。

控制回复使用FIFO；连续分析结果使用双缓冲和“最新结果覆盖未发送旧结果”
策略。即使显示控制器暂时读取较慢，也不会阻塞ADC采集或累计大量过期帧。

显示控制器应根据基频、分量幅值和谐波阶次自行合成1个或3个周期波形；
频谱只需在对应频率位置绘制离散谱线，满足原题对定性频谱的要求。

## 10. 当前限制与维护规则

1. 最多同时处理3个分量；若未来允许三个以上谐波，必须扩大生成模型、
   `TASK0729_COMPONENT_COUNT`、USB协议和显示端解析。
2. 零相位分量重构依据当前测试条件“所有初相位均为0”；若题目改为任意
   初相位，需要传输或补偿相位。
3. 频率排序后最低分量被视为基波，因此基波必须能被检测到。
4. `Expand/Generated/Task0729V4`是Simulink生成代码，不应手工添加业务逻辑；
   可维护的校准、拟合和注释应放在`task0729_processor.c/.h`包装层。
5. H743工程本身不包含最终6英寸显示与按键代码；交付完整装置时必须同时
   包含下游显示控制器工程。
